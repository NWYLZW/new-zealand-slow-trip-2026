# 移动端补充约定

以下最新反馈在冲突处优先于根 AGENTS.md 的旧布局约定：
- 挖孔避让优先保留浏览器安全区；对已实测但安全区返回0的小米2608BPX34C内屏，允许用本机UA Client Hints精确型号、内屏比例、完整窗口及Screen Orientation共同启用局部角落避让。只移动受影响的工具/头部按钮，不能缩小地图或推断所有Fold/小米均适用；外屏、分屏、型号缺失及未知方向不套用。型号只在内存中用于布局，不持久化或上传。右上挖孔时，地图工具、普通面板头部及全屏日历头部共用4px光学对齐偏移，标题/日期与操作按钮保持同一中心线；不把相机全幅取景头部当作普通标题栏移动。
- 安装后的PWA使用manifest `display: fullscreen`请求隐藏时间、电量等系统状态栏，保留`orientation: any`和现有安全区。应用安装识别兼容fullscreen与standalone；页面自身Fullscreen API不作为已安装证据。此安装模式独立于面板全屏，不通过CSS或修改手机系统设置伪装，已安装入口是否更新须实机确认。
- 标题与面包屑共用20px字号，窄屏保持同排并省略，不通过缩小字号或把操作移到第二排解决。备忘分类详情已无左侧rail，其正文不再预留空图标列。
- 住宿头部日期显示月/日，完整年份保留在提示和无障碍文本，日期单行省略。已有住宿事实全部展开，附近地理链接左侧用统一地图图标，不增加无依据数据。
- 地点面板实际内容高度不足480px时，小地图移到“地图”tab，默认仍为日历；地图tab保留URL和返回。空间充足时保留顶部地图。短高度住宿内容整体单滚动，不能由固定照片和内层tabs把正文挤成零高度；空间充足时仍允许只滚动事实。
- 当日日程空间不足时按所属主事件合并连续时段，真实间隔不能填平；极短块不强塞文案和地图按钮。空间充足恢复细节，国际多程航班仍保留飞行与换乘分段。
- 手机和平板地图节点单击仅聚焦、双击打开详情，普通地点、途经点与复合节点一致。双击需在限定时间内且属于同一逻辑目标，拖动、滚轮、多指、取消、复位清除候选；聚焦解组保留原复合节点身份。桌面和键盘仍可直接打开。
- 手机横竖屏的旅行菜单与设置顶部对齐并填满视口，不仅依赖粗指针识别；此菜单规则不改变右侧面板的分栏规则。主菜单行紧凑且触摸目标至少44px，检查更新排在安装到设备之后，状态在该行右侧单行显示。
- 菜单私密资料入口默认隐藏，持续按住菜单内左上图标3秒才显示；已解锁时显示可直接操作的锁定入口。释放、取消、移动离开、关闭或切页取消待触发长按；酒店等已有上下文解锁入口不变，隐藏入口不替代真正的保险箱加密。
- 方向偏好包含竖屏锁定、横屏锁定和跟随系统，真实调用浏览器方向API，不用CSS假旋转或自动请求全屏；不支持或拒绝时如实提示。语言、主题色和方向选项共用主题色按钮的内距、左图标槽和尺寸，主题色保留色块，未选中透明，仅选中铺彩铅底色。
- 短高度面板把原底部前后站/前后日按钮移到头部actions中、菜单按钮之前，保持原有导航语义和日期首尾禁用，不同时保留底部重复控件。短高度住宿进一步按宽度分流：宽时照片在左、信息在右；窄时照片成为入住后的独立tab，右侧使用带tooltip的入住/照片/预订政策/位置图标rail，内容不得被挤成零高度。
- 相机面板是手机横竖屏自动全屏的右侧面板例外：预览进入设置、相册或设备信息时继续全屏，返回预览也不跳回分栏；只派生布局状态，不写URL/history，也不调用浏览器全屏API，显式`fullscreen`参数始终优先。其他非相机右侧面板继续沿用既有横屏分栏规则。
- 相机预览为无纸张底色的全幅取景，头部覆盖在视频前景且不占取景高度；全屏预览不展示“相机”标题。相机图标按钮进入现有相机设置页，不展示菜单或重复设置；全屏按钮位于关闭上方，进入全屏后保留并切换为退出全屏，切换不得重启取景流。手机自动全屏中手动退出后保持分栏，旋转或进入相机设置、相册和设备信息不会立即恢复自动全屏；离开相机后清除此临时覆盖，显式`fullscreen`参数仍优先。手机竖屏固定为左上设置、右上关闭、左下相册、右下系统相机、底部中央快门；手机横屏固定为左上设置、左下关闭、右上相册、右侧正中快门、右下系统相机。两种横屏方向都使用当前物理视口边缘及对应安全区，不因方向切换把整组控件跳到对侧。所有位置保持至少44px触摸目标。
- 闪光灯与常亮灯在左上相机设置按钮下方纵排，使用共享安全区与挖孔偏移。变焦为快门左侧彩铅刻度转盘，与76px快门命中区留8px间隙；普通尺寸64x128px，手机竖屏56x76px。竖屏相册与切镜头纵排，窄分栏时整体抬高避免转盘。转盘按真实capabilities/step拖动，低倍率保留精细行程，支持键盘与取消；最多一个执行中请求和一个可替换待执行请求，读数以真实settings为准。隐藏、禁用、换镜头与卸载清理，不能声称已取消浏览器正在执行的硬件调用。
- 相机取景区支持双指张开放大、合拢缩小，复用转盘的真实硬件变焦范围、步进、latest-only队列和settings回读，不以CSS缩放冒充变焦。手势仅在可见且支持变焦的取景区接管，不捕获快门或其他控件；取消、丢失捕获、第三指、隐藏、离开、换镜头及禁用清理手势和待执行请求，正常松手提交最后倍率。浏览器已执行的硬件调用仍可能完成，不声称可撤销。
- 已识别内屏右上挖孔时，相册和切镜头按钮按排除区域的纵向高度向下避让，不向左移动；与快门及系统相机保持同一中心轴。前置取景相对原始视频流水平翻转，后置不翻转，方向依据成功获取的轨道facingMode，缺失时才回退到请求值；不把预览翻转烧录进照片或视频。
- 取景图标可在无需新增权限的设备方向事件中按物理滚转角保持直立，并扣除Screen Orientation已完成的屏幕旋转，避免重复补偿；仅在取景可见时监听，逐帧节流，退出清理，不存储或上传传感器数据。不能无手势请求DeviceOrientation权限；不支持精细角度或减少动态时只使用Screen Orientation的离散布局回退。相机预览图标提示仅允许键盘焦点触发，触摸/指针不会留下遮挡取景的文字提示，仍保留aria-label和焦点反馈。
- 相机取景图标不得依赖模糊阴影、反差描边、完整圆底、规则矩形、双层方框或卡片获得对比度。PencilIcon须把全部真实glyph几何共同膨胀后生成一块连接的、稳定种子的有机白色涂绘blob，中央安全凸包以近不透明颜料完整覆盖实际主题色墨迹、前景铅笔主笔与颗粒散丝所需邻域，而不是沿每条glyph线形成反差描边。最终可见高覆盖轮廓不能直接照搬凸包：沿凸包边段插入不同数量、不同外凸高度的稳定采样点，并局部回落至安全凸包，形成自然凸凹与缺口而保持整体连接。羽化仅出现在少量局部半透明涂绘片段，不允许等宽整圈包裹；只在画布余量充足的2至3个局部簇绘制方向、长短、间距显著不同且会错落交叉的短笔触与衰减颜料颗粒，不能按四边机械排列、形成太阳光线、规则描边、阴影或均匀光晕。中央blob连同外围落墨的总体范围至少达到实际glyph墨迹的1.2倍且不超过既有视觉包络，完整落墨保持在40px画布安全范围内，不裁断尺寸或缩放图标。前景图标笔迹使用当前主题色；纹理按`kind + geometry`稳定种子生成，使不同图标纹理不同但重绘不闪动。相机普通图标维持30px、待机快门维持36px，并使用PencilIcon默认笔宽；按钮命中盒仍分别保持44px和76px。笔触进入既有缓存，并在主题变化时刷新，不随方向动画逐帧重画或重复叠层，图标始终最后绘制在纹理上方。此配色反转只作用于相机取景按钮，不改变其他PencilIcon或状态文字背景。关闭与设置控件必须有独立前景层级及命中区域，并用盒模型、computed style、`elementFromPoint`和画布像素断言验证横竖屏可见可点。
- 相机必要状态、错误提示和录像时间在文字背后绘制颜色足够浓、细密且多角度交错的当前主题色手绘纹理，按标签类型、实际内容尺寸、主题和像素比使用稳定种子缓存刷新；笔触数量随高度增加，避免换行后背景稀疏。文字两侧保留内距，可换行且避开安全区和拍摄按钮，不扩展成整条背景栏或卡片，并保留原有`aria-live`、`role=status`与`role=timer`语义。照片、视频和系统相机导入的保存成功、重复及预览帧降级结果提示4秒后清除；新结果重新计时，旧计时器不得清除新提示，开始拍摄、隐藏、离开或卸载时清理。真正的失败信息及录制中的必要状态不按成功提示自动消失。
- 快门短按拍照，持续按住至少1秒开始录像；开始后松手继续录制，下一次激活快门才停止并保存。同一次长按释放产生的合成点击不能误停，隐藏或离开页面仍须释放相机、麦克风和录制状态。快门使用手绘外圆环和实心内圆：待机内圆为主题色、录制/准备中为红色，外环和尺寸保持不变，不使用旋转动画。内圆缩小，包含手绘描边后与外环仍须保留清楚的环形间隙，待机和录制状态一致。快门画布与其他相机工具同为45px，保留原76px命中盒，替代旧相机形图标和54px快门预览。
- 取景页不展示定位状态或定位开关，定位仍由相机设置控制并按原隐私权限逻辑写入媒体。系统相机入口用`capture`文件输入作移动浏览器的尽力提示，导入沿用原文件元数据链路，不承诺所有浏览器强制打开系统相机。构图九宫格默认开启、可持久关闭，只覆盖预览且不烧录进照片或视频。
- 共享工具图标的1.5倍本地预览只调整新版冒险地图的图标画布：左上菜单、任务/背包/相机工具、国际航段切换、缩放/复位、面板头部首槽和通用动作由30px增至45px，背包住宿/租车/活动/备忘tabs由24px增至36px；44px按钮、间距、文字和定位保持不变，超过点击区的画布用真实网格居中且不以transform缩放。相机取景普通图标与快门画布均为45px，不再次放大；此新尺寸覆盖上文历史30px/36px尺寸。地图地点、机场、途经点、集群、标签和旧`/v1`不应用此预览。
- 相机高清预览以1920x1080 ideal请求，仍由设备协商；拍照优先ImageCapture原始Blob，尺寸参数失败先保留灯光选项重试，最后退回未镜像的视频帧并准确提示。照片默认请求flash off，只有用户选择且设备声明支持才使用auto/flash；常亮灯是独立轨道能力，离开关闭。变焦和手动焦距只使用真实capabilities范围与settings回读，按镜头分开保存偏好；设置页不得为检查能力启动相机，返回取景重验。水平仪只绘真实beta/gamma读数，显式权限必须从点击请求，锁屏/失效清除，不假定传感器可用。新能力仍为本地预览，不能声称已完成真机效果验收。
- 菜单设置页固定顶部标题、返回和关闭按钮，仅设置选项section在剩余高度内纵向滚动；dialog和inner不承担该页滚动，短高平板与手机横竖屏一致。移除方向锁定结果的常驻描述，保留真实方向偏好及其应用逻辑。菜单首页和解锁页不继承设置页的滚动覆盖。
- 九宫格水平仪只旋转中央格中当前物理朝上的那一条边，其余网格、整个方框和取景均固定；复用真实重力投影与屏幕角度补偿，支持横竖和倒置，不以视口尺寸推断姿态。不再有独立浮动按钮或双线水平仪；显式方向权限入口位于相机设置的九宫格选项下，授权不等于传感器已有读数。无有效或过期读数时仅保留中性网格，隐藏、离开时清理监听与计时，减少动态时采用离散真实反馈。局部模拟测试不替代真机验收。
