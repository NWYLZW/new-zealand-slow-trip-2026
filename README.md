# 2026 新西兰南北岛松弛旅行攻略

这是一个本地静态网站项目，用来保存和继续维护你们 2026 年 9 月 28 日至 10 月 11 日的新西兰双人旅行计划。

## 本地打开

最简单的方式是直接双击 `index.html`。

如果想通过本地服务预览：

```bash
npm start
```

然后打开终端里显示的本地地址，通常是 `http://localhost:4173/`。

## 项目内容

- `index.html`：完整旅行攻略页面，包含行程总览、南岛、北岛与购物日、预订清单、注意事项。
- `images/`：页面用到的本地图片资源。

预订清单的勾选状态保存在当前浏览器的 `localStorage` 中，不会上传任何个人信息。

## 维护建议

- 修改行程内容：直接编辑 `index.html` 对应的文字。
- 替换图片：把同名图片放进 `images/` 目录即可。
- 打印或导出 PDF：打开页面后点击左侧「打印 / PDF」。
